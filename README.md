# Guest Experience Intelligence Dashboard

Dashboard estático conectado en vivo a la pestaña `Respuestas de formulario 2` de la hoja de Google Sheets indicada.

## Uso

1. Abra `index.html` en un navegador moderno o publique esta carpeta en cualquier hosting estático.
2. Mantenga la hoja compartida con permiso **Cualquier persona con el enlace → Lector** para que el navegador pueda consultar los datos sin iniciar sesión.
3. El dashboard actualiza los datos al abrirse, al pulsar el botón de actualización y automáticamente cada 60 segundos.

La configuración de la hoja está al inicio de `app.js`. Los datos de contacto se enmascaran en pantalla.
